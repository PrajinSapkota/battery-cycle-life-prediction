
# Battery Cycle-Life Prediction

## Project Overview
This project investigates battery cycle-life and Remaining Useful Life (RUL) prediction using machine learning techniques.

## Dataset
The project uses three MATLAB (.mat) battery batch files.

Original dataset:
https://data.matr.io/1/projects/5c48dd2bc625d700019f3204

The large dataset files are not included in this repository.

## Machine Learning Models
- Random Forest
- XGBoost
- Support Vector Regression

## Hyperparameter Optimisation
Random search is used to identify suitable model hyperparameters.

## Explainable AI
SHAP is used to interpret model predictions and feature importance.

## Reproducibility
- Random seed: 42
- Main notebook: notebooks/battery_life_prediction.ipynb
- Dependencies: requirements.txt

## Results
Figures and experimental result tables are included in this repository.
